# 《昨日重现》
# Typography Reference Sheet v1.0
## 字体视觉参考规范

版本：v1.0

项目：
《昨日重现（Yesterday Once More）》

用途：

本文件用于指导：

- AI UI生成
- Codex界面开发
- 字体选择
- 字体效果处理
- UI视觉统一

目标：

确保所有游戏文字具有统一的：

- 老家庭档案感
- 旧照片质感
- 记忆恢复感
- 时间沉淀感

---

# 1. Typography Visual Identity

## 核心视觉描述

《昨日重现》的文字应该像：

> 一个人在几十年后翻开旧相册时，
> 看到曾经写下的人生记录。

文字不是现代UI信息。

文字应该像：

- 写在旧纸上的标题
- 相册里的注释
- 老照片背后的日期
- 家人留下的留言

---

# 2. 字体整体风格关键词

所有字体必须符合：

```

nostalgic
aged paper
family archive
handwritten memory
warm brown ink
old photograph
Chinese literary feeling

```

中文描述：

```

怀旧
家庭档案
泛黄纸张
手写记录
旧时代印刷
温暖墨色
人生记忆

```

---

# 3. 字体层级参考

```

Typography

1. Main Title
   游戏标题/核心标题

2. Chapter Title
   章节标题

3. Body Text
   普通说明文字

4. Handwritten Memory
   情感文字

5. System Label
   日期/英文/编号

```

---

# 4. Main Title Reference
# 主标题字体参考

## 使用场景

例如：

```

昨日重现

记忆恢复报告

```

---

## 视觉目标

参考：

旧书封面标题。

不是：

游戏Logo字体。

---

## 字体感觉

必须具有：

- 毛笔书写感
- 墨迹厚度变化
- 笔锋明显
- 轻微自然倾斜
- 人工书写痕迹


---

## 字体结构

要求：

```

粗笔画
+
自然留白
+
不完全规则
+
墨迹扩散

```

---

## 禁止：

不要：

```

现代黑体
科技字体
电竞字体
机械字体
过度工整字体

```

---

## 渲染效果

文字不是纯色：

应该：

```

字体

↓

深棕墨色

↓

纸张吸收

↓

轻微模糊

↓

旧化

```

---

# 5. Chapter Title Reference
# 章节标题字体参考

## 示例

```

第二章 · 接女儿放学

```

---

## 定位

像：

家庭档案中的章节标题。

---

## 风格：

比主标题：

- 更规整
- 更容易阅读
- 更像记录文字


---

## 特征：

```

手写楷体
+
旧档案标题
+
温暖感

```

---

## 排版：

居中。

上下留白。

类似：

```

────────────

第二章 · 接女儿放学

────────────

```

# 7. Handwritten Memory Reference
# 手写记忆字体参考

## 核心等级：

★★★★★


这是游戏情感表达的重要部分。


---

## 使用：

- 女儿留言
- 日记
- 老人内心独白
- 纸条


---

## 视觉目标：

像真实的人写下：

```

爸：

今天太阳很好。

记得吃药。

```

---

## 字体特点：

需要：

```

笔画粗细变化

书写速度感

轻微歪斜

不完全统一

个人习惯

```

---

## 禁止：

不要：

```

可爱字体
少女手帐字体
儿童字体
漫画字体

```

# 10. 字体材质效果参考


所有重要文字：

不能像悬浮文字。

需要：

```

Text

↓

Ink

↓

Paper absorption

↓

Aged texture

```

---

## 推荐效果：

### 墨迹扩散

边缘轻微柔化。


### 纸张融合

文字颜色进入纸张。


### 时间磨损

部分笔画轻微褪色。

---

# 11. 动态文字效果参考


## 新记忆出现

动画：

```

模糊文字

↓

墨迹聚合

↓

清晰文字

```


时间：

0.5-1秒


---

## 记忆恢复

例如：

```

YY

↓

丫丫

```


效果：

像老人重新想起这个名字。


---

## 记忆消退

效果：

```

完整文字

↓

缺失

↓

模糊

↓

消散

```

# 12. UI按钮字体参考


按钮文字：

例如：

```

开始回忆

继续昨日

章节选择

```

---

要求：

不是普通按钮文字。

应该像：

贴在相册上的标签。


---

默认：

```

低饱和棕色

```

Hover：

```

墨色增强

纸张亮起

文字更加清晰

```

# 13. AI视觉参考描述

生成字体/UI时加入：

```

Typography style:

Chinese nostalgic family archive typography.

Main title:
aged Chinese brush handwriting,
warm dark brown ink,
old book cover feeling.

Chapter title:
handwritten archive heading,
traditional Chinese document style.

Body:
old printed family record text,
soft brown ink.

Handwriting:
real personal handwriting,
uneven strokes,
emotional memory notes.

All text should appear printed or written on aged paper,
not floating digital UI text.

```
